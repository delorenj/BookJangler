Every spoken word was synthesized on the local RTX 3090

307 requests (11 voice-design, 296 chapter chunks) went to the self-hosted VoxCPM2 service (openbmb/VoxCPM2, package 2.0.3) on big-chungus's NVIDIA RTX 3090. 1461 s of synthesis produced the 50:20 chapter. No paid TTS provider and no cloud fallback were called. Quality checks used a local faster-whisper model on CPU.

The LLM was a subscription route: $0 marginal gateway charge

OpenCode's sol-6.1 maps to gateway route automaticai/personal/sol-6.1, native gpt-6.1-sol on account openai-personal, billed as subscription. All 202 requests were matched to gateway rows (exact token tuple and time) and every one settled at 0 quota in the NewAPI ledger. The fixed subscription fee is not allocated to this experiment; the message-to-row link is an inference because the gateway rows carry no message key (see Coverage).

$29.40 is an API-equivalent estimate, not a bill

If the same 17,277,714 tokens had been bought at published pay-as-you-go GPT-6.1 Sol rates ($2.00 uncached input, $0.10 cache read, $10.00 output per million) it would cost about $29.40. Nobody was charged this.

Reconciliation notes

  • Gateway rows in the window: 930. 202 are this experiment's requests (matched as described above, all automaticai/personal/sol-6.1 on openai-personal, subscription class). The other 728 are concurrent traffic from other agents and are not charged here: anthropic/claude-opus-5-5 239; anthropic/claude-sonnet-5-5 41; moonshot/kimi-for-coding 3; openai/gpt-6.1-sol 371; openrouter/deepseek/deepseek-v4-flash-0731 32; zai/glm-5.3 1; zai/glm-5.3-flash 41.
  • Phase attribution of main-session messages follows actual tool calls first, then the latest child phase start; uncertain placements are flagged in the ledger.
  • Lifecycle events with no tool call (session and turn markers) appear as phase 'orchestration'; their tokens sit inside the other phases.
  • Exhausting stored events proves retrieval coverage, not that every native/provider action emitted an event.
  • No raw prompts, transcripts, tool inputs/outputs, environment values, credentials, proof hashes or audio fingerprints persisted.
  • Upstream model/account facts in unmatched records describe concurrent traffic only, not the BookJangler model route.
  • Gateway event schema has usage and subscription/metered class but no monetary charge amount. Pricing is outside this collector.
  • Subscription utilization percentages and cache discounts cannot be inferred from token counts.
  • Search invocation completion is not upstream success or a billable receipt; retries are known only with structured attempt receipts.
  • Post-snapshot completion/listening exchange is separately recorded; all report work is excluded from core.
  • Finite 10-minute envelope-lag allowance can miss later backfilled settled events; no claims of unbounded completeness.
  • Gateway rows are linked to messages by an inferred match (the rows have no message key); NewAPI quota was read per matched request from the gateway database, while the CandyStore usage schema itself has no monetary amount.
  • Missing values mean unknown. Event matching alone does not prove complete session coverage or settled billing.
